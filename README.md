MEMAHAMI ISSUE

1. Apa fungsi GitHub Issue?
GitHub Issue berfungsi untuk mencatat, membahas, dan mengelola tugas, masalah (bug), atau fitur yang akan dikerjakan dalam sebuah project.

2. Mengapa pekerjaan sebaiknya dicatat sebagai Issue?
Agar pekerjaan menjadi lebih teratur dan mudah dipantau. Anggota kelompok dapat mengetahui apa yang harus dikerjakan, siapa yang mengerjakan, dan apakah tugas tersebut sudah selesai atau belum.

3. Apa perbedaan Issue dengan Commit?

Issue → berisi tugas atau masalah yang harus dikerjakan.
Commit → berisi perubahan kode/file yang sudah dikerjakan dan disimpan dalam riwayat Git.

Contoh:

Issue: Membuat halaman Home
Commit: "Menambahkan halaman Home dan hero section"

Jadi, Issue = apa yang harus dikerjakan, sedangkan Commit = perubahan yang sudah dikerjakan.
